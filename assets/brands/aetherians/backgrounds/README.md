# Aetherians video backgrounds

Illustrations from the Aetherians books (made with ChatGPT image generation for the
owner's DPF project), used as moving backgrounds in Aetherians videos.

- These are **video-size copies** (1600 px on the long side). The full-resolution
  print versions are kept privately, outside this public repository.
- Folders follow the books: `the_turning_zodiac/` (12 signs + covers),
  `crystals_and_mystic_frequencies/`, `the_orphic_sky/`.
- Sharpened by a 4x AI upscale (Real-ESRGAN realesr-general-x4v3) before resizing.
- Owner's work; not licensed for reuse by others.
