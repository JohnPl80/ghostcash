# Video templates

Configurable-without-code visual settings for the three CLAUDE.md
section 17 templates (colors, font, sizes, transition timing). The
scene *structure* itself (which scenes exist, in what order) is fixed
in `ghostcash.video.renderer` - see each file's comments for why.

- `information.yaml` - Template A: HOOK -> POINT 1-3 -> CTA
- `list.yaml` - Template B: "3 things..." -> 1 -> 2 -> 3 -> CTA
- `problem_solution.yaml` - Template C: PROBLEM -> WHY -> SOLUTION -> CTA
